# Restaurant Tips Analysis – Exploratory Data Analysis with Python

## Project Overview
This project explores restaurant transactions to identify patterns in customer bills, tips, and dining habits.

The objective is to extract meaningful insights through data cleaning, exploratory data analysis (EDA), statistical analysis, and visualization.

## Dataset
- Source: Seaborn Tips Dataset
- Initial records: 244
- Records after cleaning: 243
- Features: 7

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Analysis
The project includes:
- Data inspection and cleaning
- Missing values and duplicate detection
- Sales analysis by day
- Lunch vs Dinner comparison
- Correlation analysis between total bills and tips
- Tip percentage analysis
- Smoker vs Non-Smoker comparison
- Data visualization and dashboard creation

## Key Findings
- Saturday generated the highest total bill amount.
- Sunday had the highest average bill.
- Dinner had more transactions and higher average bills than lunch.
- Total bills and tips showed a positive correlation (0.675).
- Average tip percentages were similar between smokers and non-smokers.
